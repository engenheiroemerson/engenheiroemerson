# 👨🏻‍💻 Sobre mim

Sou apaixonado por construir soluções de engenharia inteligentes integrando **Engenharia Elétrica**, **Engenharia de Software**, **Sistemas Embarcados**, e **Inteligência Artificial**.

Meus interesses abragem engenharia multidisciplinar, incluindo sistemas de energia elétrica, automação industrial, energia renovável, eletrônica embarcada, computação em nuvem, robótica e desenvolvimento de software inteligente.

Atualmente cursando Bacharelado em Engenharia Elétrica, continuo expandindo meus conhecimentos em sistemas de energia inteligentes, eletrônica de potência, IoT, automação industrial, tecnologias embarcadas, aprendizado de máquina e transformação digital.

Meu objetivo é contribuir para projetos de engenharia inovadores que combinam sistemas elétricos, software, tecnologias embarcadas e inteligência artificial para criar indústrias mais inteligentes, eficientes, conectadas e sustentáveis.
